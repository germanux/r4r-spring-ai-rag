# R4R canonical assignment command

PC and LP are equivalent fullstack workers. The only task authority is
`.opencode/task-plan.json`; the only current work authorization is the fresh
`runtime/control/<WORKER>/assignment.json` generated by Ring.

For the assigned task:

1. Read `AGENTS.md`, the exact canonical plan entry and its command document.
2. Verify that the assignment ID, task ID, dependencies, expiry and `write_scope`
   match the canonical plan.
3. Run the exact task gate before editing.
4. Use the first current failure and bounded evidence to make one coherent repair.
5. Write only paths allowed by the task's `allowed_paths`.
6. Run the exact gate again and stop after the controller records the result.

Never select another task, bypass a blocked status, broaden scope or run Git write
commands. Return unresolved ambiguity to Ring. Sol is invoked only by Ring after an
explicit `ESCALATE` decision.
