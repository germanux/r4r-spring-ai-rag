Diagrama y tecnologías
  • Java 21, Spring Boot y Spring AI coordinan el RAG bilingüe.
  • Nomic embeddings y PostgreSQL/pgvector recuperan documentación; AWS Lambda Java 21 y S3 Vectors ofrecen respaldo.
  • Ollama utiliza PC, portátil y OpenAI como respaldo configurado. El NAS y su conexión siguen siendo dependencias.
  • SSE muestra las etapas y los proveedores reales. Pruebas automatizadas verifican contratos e interacción.
