Recuperación

La consulta se transforma en embedding y se compara contra fragmentos sobre reformas, materiales y presupuestos.

Grounding

Los textos recuperados se etiquetan y se entregan al modelo como contexto verificable para responder.

Abstención

Si la pregunta no encaja con la documentación de Riansares 4R, el sistema devuelve abstención.

Despliegue

La API y PostgreSQL van en Docker; la inferencia se apoya en Ollama con modelo local conectado a la demo.
