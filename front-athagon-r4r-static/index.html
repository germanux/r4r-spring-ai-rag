QUÉ DEMUESTRA
01

Recupera

Busca fragmentos relevantes en la base de conocimiento antes de generar una respuesta.

02

Responde con evidencia

El modelo recibe los fragmentos recuperados y construye la respuesta apoyándose en ellos.

03

Cita las fuentes

La respuesta conserva referencias trazables a los documentos y fragmentos utilizados.

04

Sabe abstenerse

Si no encuentra evidencia suficiente o la evidencia no sirve, devuelve una abstención en lugar de inventar.

Retrieval

La pregunta se convierte en embedding y se buscan los fragmentos más próximos en pgvector.

Grounding

Los fragmentos recuperados se etiquetan y se entregan al modelo como evidencia para la respuesta.

Abstención

El sistema puede detenerse por falta de evidencia antes de generar o después, si el modelo la considera insuficiente.

Despliegue

La API y PostgreSQL se ejecutan en contenedores Docker; la inferencia pesada se realiza con Ollama.
