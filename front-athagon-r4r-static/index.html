Retrieval

Question → embedding → pgvector similarity search → up to 5 evidence chunks above the configured minimum score.

Grounded generation

Retrieved chunks are labeled [S1]…[S5] and passed to the local model as the only permitted evidence.

Abstention

The service can abstain before generation when retrieval is weak, or after generation when the model marks the evidence insufficient.

Deployment

Spring Boot + PostgreSQL/pgvector run as Docker containers on Synology; Ollama runs on the local inference host.
