Qué puedes preguntarle
  • Orientación inicial: qué información hace falta para valorar una obra.
  • Conceptos técnicos: diferencias entre solera, solado, morteros o sistemas.
  • Impermeabilización y reparación: humedades, cubiertas, filtraciones y acabados.
  • Presupuestos orientativos: alcance, partidas y criterios de medición.
Importante: no es un chat genérico. La demo está pensada para preguntas relacionadas con la actividad de Riansares 4R.

Recuperación

La consulta se transforma en embedding y se compara contra fragmentos sobre reformas, materiales y presupuestos.

Grounding

Los textos recuperados se etiquetan y se entregan al modelo como contexto verificable para responder.

Abstención

Si la pregunta no encaja con la documentación de Riansares 4R, el sistema devuelve abstención.

Despliegue

La API y PostgreSQL van en Docker; la inferencia se apoya en Ollama con modelo local conectado a la demo.
