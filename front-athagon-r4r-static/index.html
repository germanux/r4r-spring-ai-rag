01

IA en equipos propios (Self-Hosted AI)

Los modelos funcionan en ordenadores propios, sin depender de un proveedor externo de inferencia para las generaciones locales. Ollama es el software que permite ejecutar estos modelos de lenguaje en los equipos locales.

02

Respaldo automático (Automatic failover)

Si falla el ordenador principal, el sistema intenta utilizar automáticamente el ordenador de respaldo para generar la respuesta. Si ninguno está disponible, informa del error.

03

Cita las fuentes

Antes de responder, recupera fragmentos relevantes de la documentación de Riansares 4R. La respuesta cita documentos y secciones para poder comprobar sus fuentes.

04

Se frena fuera de dominio

Si la pregunta no encaja con el conocimiento cargado, se abstiene en lugar de aparentar seguridad.

La web es pública y las consultas en inglés pueden utilizar un servicio externo de traducción. La IA local describe dónde se generan las respuestas.
