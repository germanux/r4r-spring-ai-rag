# Benchmark 05 — guided agentic cycle

The orchestrator must remain smaller than the product code it coordinates.

Cycle:

1. deterministic pre-gate;
2. one bounded OpenCode edit epoch;
3. deterministic post-gate;
4. evidence bundle;
5. optional Codex JSON review;
6. manual commit.

No automatic task selection, auto-commit, multi-epoch loop or Markdown-based machine API.
